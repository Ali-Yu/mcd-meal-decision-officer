【麦麦饭点决策】 时段：工作午餐｜人数：1｜预算：≤35元
A. 最省方案 省钱优先
组合：麦香鸡 + 中薯条 + 中可乐
实付 ¥24.5（原价 ¥32）
热量 780 kcal
决策理由：工作午餐优先性价比，经典组合快速解决饥饿，放弃了更高蛋白的板烧以控制预算。
B. 最均衡方案 推荐
组合：板烧鸡腿堡套餐（可乐换无糖）
实付 ¥32.0
热量 690 kcal
决策理由：兼顾饱腹与下午不困，无糖可乐降低糖分负担，适合工作日中午。
C. 最开心方案 满足优先
组合：麦辣鸡腿堡 + 麦乐鸡5块 + 中可乐
实付 ¥34.5
热量 920 kcal
决策理由：重口解压，适合压力大的工作日中午，但热量偏高，下午可能犯困。

【麦麦饭点决策】 时段：加班宵夜｜人数：1｜预算：≤40元
A. 最省方案 省钱优先
组合：麦香鸡 + 小份薯条
实付 ¥18.5
热量 520 kcal
决策理由：宵夜时段优先低负担，放弃饮料和多余小食，快速垫一下即可。
B. 最均衡方案 推荐
组合：板烧鸡腿堡（去酱）+ 玉米杯
实付 ¥29.0
热量 480 kcal
决策理由：宵夜核心是「不撑」，去酱降低油脂，玉米提供饱腹感且易消化。
C. 最开心方案 满足优先
组合：麦辣鸡腿堡 + 麦旋风
实付 ¥38.5
热量 890 kcal
决策理由：加班后想吃点甜的奖励自己，但热量较高，仅建议偶尔选择。

【麦麦饭点决策】 时段：周末聚餐｜人数：3｜人均预算：≤50元
A. 最省方案 省钱优先
组合：3份麦香鸡套餐 + 共享薯条
合计 ¥89（人均 ≈¥29.7）
总热量约 2100 kcal
决策理由：极致控制预算，但口味单一，且未照顾控卡和不吃辣的朋友。
B. 最均衡方案 推荐
组合：板烧鸡腿堡套餐×1 + 麦辣鸡腿堡套餐×1 + 麦香鱼套餐×1（无糖可乐）
合计 ¥128（人均 ≈¥42.7）
总热量约 1950 kcal
决策理由：一人一份不同主食，覆盖不吃辣与控卡需求，口味有差异但不踩雷，公平性最高。
C. 最开心方案 满足优先
组合：新品鸡腿堡×2 + 麦辣鸡翅 + 麦旋风×2 + 共享小食
合计 ¥148（人均 ≈¥49.3）
总热量约 2400 kcal
决策理由：氛围感拉满，适合庆祝或放松聚餐，但预算接近上限且热量偏高。
